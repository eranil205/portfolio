WordPress Development

WordPress Website Migration

Problem

A client needed to move a live WordPress site to new hosting without disrupting existing search rankings, contact forms, or WooCommerce checkout functionality.

Investigation

Audited the current hosting environment, DNS records, PHP version, and the full theme/plugin stack to map every dependency that could break during the move.

Solution

Migrated the site through a staged environment, verified theme and plugin compatibility, and cut over DNS with a controlled TTL rollout to avoid downtime.

Outcome Successfully migrated the live website while preserving critical functionality and SEO continuity.

WooCommerce Optimization

WooCommerce Performance & Troubleshooting

Problem

A WooCommerce store was loading slowly and throwing intermittent checkout errors whenever traffic spiked.

Investigation

Used Query Monitor to trace slow database queries, reviewed the active plugin stack for conflicts, and checked how caching was interacting with cart and checkout pages.

Solution

Resolved a plugin conflict, optimized the slowest product queries, and configured page and object caching tuned to exclude WooCommerce's dynamic pages.

Outcome Improved site performance and stability, creating a faster and more reliable checkout experience.
WooCommerceQuery MonitorCaching
Technical SEO

Technical SEO Audit & Indexation Improvement

Problem

A large share of a site's pages weren't appearing in Google's index months after being published.

Investigation

Ran a full Screaming Frog crawl alongside the Search Console Index Coverage report to see where crawl budget was being wasted on low-value or duplicate URLs.

Solution

Corrected faulty canonical tags, pruned thin and duplicate pages, tightened internal linking to priority pages, and resubmitted a cleaned-up XML sitemap.

Outcome Removed key indexation barriers and improved crawl efficiency for priority pages.
Search ConsoleScreaming FrogXML Sitemaps
Structured Data

Structured Data Implementation

Problem

A site had little to no structured data in place, so none of its pages were eligible for rich results in search.

Investigation

Audited the page templates for missing schema opportunities and validated the existing markup against Google's Rich Results Test and the Schema.org vocabulary.

Solution

Implemented Product, Article, and FAQ schema across the relevant templates and iterated on each type until it validated cleanly with no errors or warnings.

Outcome Implemented validated structured data across key templates to improve rich result eligibility.
Schema.orgRich Results TestSearch Console
Google Merchant Center

Product Feed Troubleshooting

Problem

A large share of products were failing to sync from the store's data source into Merchant Center, so they never reached Shopping ads.

Investigation

Traced the data flow from the CMS through the feed file into Merchant Center's diagnostics to pinpoint exactly where the sync was breaking down.

Solution

Corrected malformed attributes at the data source, fixed a feed formatting issue, and set up a scheduled fetch to keep the feed reliably in sync going forward.

Outcome Restored reliable product synchronization and improved product availability in Merchant Center.
Merchant CenterProduct FeedMerchant API
Feed Diagnostics

Product Disapproval Resolution

Problem

A batch of products was disapproved in Merchant Center, pulling them out of active Shopping campaigns.

Investigation

Reviewed the Product Diagnostics report against Google's Shopping policies to identify exactly which attributes were triggering each disapproval.

Solution

Corrected the flagged product data, filled in missing required attributes, and applied custom labels to make future policy checks easier to monitor.

Outcome Resolved product data issues and restored affected products to an eligible status.
Merchant CenterProduct DiagnosticsCustom Labels
GA4 Implementation

GA4 & GTM Setup with eCommerce Tracking

Problem

A store had GA4 installed but wasn't capturing purchases, add-to-cart actions, or other key eCommerce events.

Investigation

Inspected the site's data layer in GTM Preview mode and cross-checked event firing against GA4 DebugView to find where events were missing or malformed.

Solution

Rebuilt the data layer to pass complete eCommerce event data, configured the matching GTM tags and triggers, and validated every event through to GA4 reporting.

Outcome Enabled reliable end-to-end tracking of key eCommerce events and customer actions.
GA4Google Tag ManagerData Layer
Conversion Tracking

Cross-Domain Conversion Tracking Debugging

Problem

Conversions were being under-reported because sessions were splitting whenever customers moved from the main site to a separate checkout domain.

Investigation

Used GTM Preview mode and GA4 DebugView to trace the client ID across the domain handoff and confirm exactly where the session linkage was breaking.

Solution

Configured cross-domain measurement in GA4, updated the GTM triggers to pass the client ID correctly across domains, and re-tested the full purchase flow end to end.

Outcome Restored cross-domain session continuity and improved conversion attribution accuracy.
GTMGA4 DebugViewGoogle Ads
